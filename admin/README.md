# Cecile 内容管理后台原型

打开 `index.html` 即可使用。也可以从项目根目录运行静态网页服务后访问 `/admin/`。

- Portfolio：勾选首页图片组、选择组内展示图片、调整图片组顺序、环形布局预览。展示图独立于项目封面。
- Selected work：新增、编辑、删除项目；多选或拖拽添加项目图片，预览缩略图、长按拖动交换图片位置、移除图片及指定封面；新增、删除分类；搜索与分类筛选。删除可撤销，删除分类不会删除项目。
- Hello：编辑问候、名字、院校、专业、专长、板块标题和联系方式，实时预览。
- 保存更改：保存在当前浏览器的 IndexedDB 数据库中，兼容读取旧版本草稿。换浏览器或清除浏览数据后不会保留。
- 导出配置：下载 JSON 数据备份，供后续正式接入使用。

这是可交互的后台设计原型，不包含登录、服务端数据库、远程文件上传或 GitHub 发布功能；不会修改线上网站。图片上传仅在当前浏览器读取，每张图片最大 10MB，按原始文件字节读取，不缩放、不重新编码、不压缩，本地存储满时请导出备份。

依赖上一级目录的 projects.js、assets 和 fonts。原站文件保持不变。
